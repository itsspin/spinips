# SpinUI Pearlescent

An optional native skin with black-pearl surfaces, ivory typography,
champagne edges, seafoam highlights and rose-lilac selection accents.
Resource colors and the red/white attack perimeter retain their meaning.

Choose spinui_pearlescent in Load UI Skin. The same theme is available in
Loremaster Settings. All gameplay bindings are shared with SpinUI Reloaded.
Generated by python tools/build_spinui_pearlescent.py; do not edit the output.
